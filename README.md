## B. Langkah-Langkah Praktikum

### 1. Membuat Folder Project (`Lab2Web`) dan Directory `media/`
Membuat folder kerja utama bernama `Lab2Web` beserta folder `media/` untuk menyimpan berkas multimedia, file `pertanyaan10soal.txt`, serta file pendukung lainnya.
![Struktur Directory Project](./mediaa/Screenshot%202026-10-12%20233014.png)

### 2. Menuliskan Kode Tabel Data Mahasiswa (`index.html`)
Menyusun struktur dasar HTML5 pada `index.html` dan menambahkan tabel data mahasiswa (`NIM`, `Nama`, `Program Studi`) menggunakan tag `<table>`, `<tr>`, `<th>`, dan `<td>`.
![Kode Tabel Data Mahasiswa](./mediaa/Screenshot%202026-10-12%20234745.png)

### 3. Menuliskan Kode Tabel Nilai dan Form Registrasi (`biodataa.html`)
Membuat tabel nilai praktikum dengan tag `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, serta penggabungan kolom (`colspan`). Selain itu, membuat struktur form registrasi mahasiswa.
![Kode Tabel Nilai dan Form](./mediaa/Screenshot%202026-10-12%20234802.png)

### 4. Menambahkan Elemen Form Lengkap dan Atribut Validasi
Menambahkan berbagai jenis input pada form seperti `text`, `email`, `password`, `date`, `radio` (jenis kelamin), `checkbox` (keahlian), `select` (program studi), `textarea` (alamat), serta atribut validasi seperti `required` dan `minlength`.
![Kode Form dan Validasi](./mediaa/Screenshot%202026-10-12%20234815.png)

### 5. Menuliskan Kode Tag Semantic dan Pemutar Multimedia
Menyusun struktur semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`) serta menambahkan tag `<audio>` dan `<video>` pada file `index.html`.
![Kode Semantic dan Multimedia](./mediaa/Screenshot%202026-10-12%20234557.png)

### 6. Menampilkan Tabel Data Mahasiswa dan Form di Browser
Membuka file `biodataa.html` di browser untuk menguji tampilan tabel data mahasiswa, tabel nilai praktikum, dan elemen form registrasi.
![Tampilan Tabel dan Form di Browser](./mediaa/Screenshot%202026-10-12%20230845.png)
![Tampilan Tabel dan Form di Browser](./mediaa/Screenshot%202026-10-12%20230901.png)

### 7. Menampilkan Halaman Utama dan Pemutar Multimedia di Browser
Membuka file `index.html` melalui browser untuk melihat hasil penerapan struktur semantic serta pemutar audio dan video.
![Tampilan Utama dan Multimedia di Browser](./mediaa/Screenshot%202026-10-12%20230816.png)
